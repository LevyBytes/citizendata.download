## Hangar Link ship names

The Hangar Link and Fleetview export names each ship the way Hangar Link does, so that an exported file shows its ships in Fleetview. Two lists are bundled for that purpose in `docs/scripts/hangar-link-ships.js`:

- Ship identifiers and the item titles listed for them, taken from Hangar Link's public ship catalogue at `https://hangar.link/ships.json`. Prices, images, and statistics from the catalogue are not included.
- Alternate spellings of ship names, in `scripts/hangar-link-title-aliases.json`, taken from the script of Hangar Link's own website, which accepts those spellings.

Hangar Link and Fleetview are independent projects. CitizenData is not affiliated with them, and these lists are not relicensed by this project's MIT License.
